## 一键开服到底要几步

买完游戏云，在配置页直接选 Terraria + tShock，进控制台下拉到 MCSManager 面板，按提示启动就行。整个过程不需要 SSH，也不需要敲 Linux 命令，服务端是预装好的，Minecraft 各版本、泰拉瑞亚、饥荒都是开箱即用。资料里提到新手照着走 10–15 分钟能完成，看到 `Server started` 就可以把 IP 和端口发给朋友。

面板服和 VPS 游戏云的区别在于系统权限。跑泰拉瑞亚，面板服够用；只有你需要改系统层配置、装额外服务时，才需要 VPS 游戏云。

## NAT 还是独立 IP，泰拉瑞亚私服要不要多花这笔钱

雨云不少机型默认 NAT，也就是和别人共用一个公网 IP，只能开固定数量的端口映射，资料里的说法是 10–15 个。泰拉瑞亚默认端口是 7777，配置一个端口转发就够，所以纯游戏服买 NAT 完全能跑。

独立 IP 要另外加钱：海外 IP 5 元/个/月，香港移动高防 IP 40 元/月，宿迁独享 IP 因为带 150G 防御要 150 元/月，比服务器本身还贵。NAT 机型拿来学习 Linux、做内网穿透都没问题，但不能直接搭网站对外访问。你如果只是开个泰拉瑞亚服给朋友，这笔钱不用花；要同时建站，才需要独立 IP。

## 开服流程与四个启动参数

1. 通过优惠入口注册账号，绑定微信领取首月 5 折新人券。
2. 购买游戏云，配置页选 Terraria + tShock（或原版服务端），机房选宿迁、十堰或广州。
3. 进控制台，下拉到 MCSManager 面板，按提示启动服务器。
4. 需要在启动脚本末尾加参数：
   - `-maxplayers 8`：设置最大玩家数
   - `-password 你的密码`：给服务器加密码
   - `-difficulty 1`：设置难度，0 经典 / 1 专家 / 2 大师 / 3 旅程
   - `-language zh-Hans`：让服务端输出中文
5. 看到 `Server started` 后，把 IP 和端口发给朋友。

参数写在启动脚本末尾，保存后重启服务生效。`-maxplayers` 不要超过 16，超过官方默认上限也不会生效。
